## 第一章：伪钞大师与卡迈克尔数（问题本质与直觉）

### 1.1 通俗隐喻：验钞机、普通假钞与绝对伪钞制造大师
想象你开了一家银行，为了防止收到假钞（合数），你买了一台老式的验钞机。这台验钞机遵循一条著名的规律（费马小定理）：**只要是真钞（素数），在紫外线灯照射特定波长 a 时，反射回来的荧光代码必定是 1。**

- **普通假钞（普通合数）**：制造工艺很糙，只要随便换个底数 a 照一下，立马现原形，报警器狂响；
- **费马伪素数（初级伪钞）**：有个造假者制造出了“341 号假币”，这叠假币在 2 号波长（以 2 为底数）照射下，居然也能反射出真钞代码 1！但是，只要银行职员换成 3 号波长照射，它就瞬间露馅；
- **卡迈克尔数（绝对伪钞制造大师）**：这是数论世界里最狡猾的高智商罪犯。它明明是假钞（合数），但它的工艺精湛到了极致——**无论你换用任何一台合法的验钞机（所有与它互素的底数 a），它反射出的荧光代码永远恒等于 1！**

在银行看来，它完完全全就是真钞！这就是现代密码学（如 RSA 密钥生成、Miller-Rabin 素性检验）必须全力防范的病态对象。

### 1.2 中文伪代码：卡迈克尔数的原生判定逻辑

```text
算法 卡迈克尔数原生定义判定(自然数 n):
    输入: 一个自然数 n
    输出: 布尔值 (真表示 n 是卡迈克尔数，假表示不是)

    // 步骤一：门槛检验
    如果 n ≤ 2:
        返回 假  // 定义要求必须大于 2

    // 步骤二：身份检验（必须是合数）
    如果 n 是素数:
        返回 假  // 真钞不是伪钞

    // 步骤三：全域底数检验（骗过所有与它互素的底数）
    对于 每一个 与 n 互素的正整数 b:
        计算 同余式余数 = (b 的 (n - 1) 次方) 模 n
        如果 同余式余数 ≠ 1:
            返回 假  // 只要有一个底数照出原形，就不是绝对伪钞大师

    // 如果通过了全部互素底数的检验
    返回 真
```

### 1.3 严谨学术：严格数学定义与群论刻画
1. **费马小定理（Fermat's Little Theorem）**：  
   若 p 为素数，则对任意与 p 互素的正整数 a，a 的 (p - 1) 次幂模 p 余 1：
   > a^(p - 1) ≡ 1 (mod p)
2. **费马伪素数（Fermat Pseudoprime）**：  
   若奇合数 n 与某个特定底数 a 满足 a^(n - 1) ≡ 1 (mod n)，则称 n 是以 a 为底的费马伪素数。最小的例子是 341（341 = 11 × 31），2^340 模 341 余 1。
3. **卡迈克尔数（Carmichael Number，绝对伪素数）**：  
   大于 2 的正整数 n，若满足：
   - n 是合数；
   - 对**所有**满足与 n 互素的正整数 a，均有 a^(n - 1) ≡ 1 (mod n)；
   则称 n 为卡迈克尔数。
4. **代数本质（群论视角）**：  
   在模 n 既约剩余系构成的乘法群 (ℤ/nℤ)ˣ 中，卡迈克尔数的充要条件是该群的**群指数（Exponent）整除 (n - 1)**。

## 第二章：历史上的刑侦画像（科瑟尔特准则与它的工程代价）

### 2.1 通俗隐喻：通缉画像的三张面孔与因数分解的包袱
要揪出这个完美伪钞大师，直接按照定义去试世界上的所有底数是不可能的（因为互素的数无穷无尽）。
1899 年，数学家阿尔温·科瑟尔特（Korselt）公布了一份“通缉画像”：想要成为绝对伪钞大师，必须**同时长齐以下三张面孔**：
1. **身份必须是假钞**（它必须是合数，不能是素数）；
2. **生产模具绝对不能有重合**（无平方因子，分解出的各个素因子互不相同，不能有 p² 这样的零件）；
3. **各个零件齿轮比必须精准咬合**（对它的每一个素因子 p，齿轮比 (p - 1) 都必须能够整除总齿轮数 (n - 1)）。

数学家在 561 这个数字上验明正身：
- 561 分解为 3 × 11 × 17（三个素数互不相同，满足特征 1 和 2）；
- 齿轮校验：(3 - 1 = 2) 整除 560；(11 - 1 = 10) 整除 560；(17 - 1 = 16) 整除 560（560 / 16 = 35）。三个齿轮全部严丝合缝！
于是 561 成为人类发现的第一个卡迈克尔数。

**但是，用这套刑侦画像去排查嫌犯，需要背负巨大的工程包袱**：
你必须先对每个候选数进行**完全因数分解**，并且必须向机器证明分解出的每一个零件**都是真正的素数**！在形式化系统里，因数分解和素性证明极其昂贵。

### 2.2 中文伪代码：科瑟尔特准则判定算法

```text
算法 基于科瑟尔特画像判定(自然数 n):
    输入: 自然数 n
    输出: 布尔值

    如果 n ≤ 2 或者 n 是偶数:
        返回 假

    // 繁重的工程包袱 1：必须彻底做素因数分解
    素因子列表 = 获取所有质因数(n)

    // 繁重的工程包袱 2：验证无平方因子
    如果 列表中存在重复素因子:
        返回 假  // 有平方因子，直接排除

    // 繁重的工程包袱 3：逐一检查每个素因子的齿轮咬合
    对于 素因子列表中 的 每一个素数 p:
        // 关键难点：必须先证明 p 是真正的素数！
        如果 (n - 1) 不能被 (p - 1) 整除:
            返回 假  // 齿轮咬合失败，排除！

    // 全部零件通过咬合检验
    返回 真
```

### 2.3 严谨学术：科瑟尔特定理与 Mathlib 官方悬空待办
1. **科瑟尔特判别定理（Korselt's Criterion, 1899）**：  
   整数 n > 2 是卡迈克尔数，当且仅当：
   - n 是合数；
   - n 是无平方因子数（Squarefree，即对任意素数 p，p ∣ n 推出 p² ∤ n）；
   - 对 n 的任意素因子 p，(p - 1) ∣ (n - 1)。
2. **国际官方数学库的悬空 TODO**：  
   在国际顶级交互式定理证明库 `Mathlib.NumberTheory.CarmichaelNumber` 中，官方作者 Felix Pernegger 形式化证明了 561 满足 Korselt 准则，但留下了著名的待办事项：
   ```lean
   /-!
   ## TODO
   * Prove (in a computationally efficient manner) that there are no Carmichael numbers
     less than 561.
   -/
   ```
   如何以“计算高效的形式”证明小于 561 的数全都不满足条件，正是核心攻坚目标。

## 第三章：1144 亿算力大爆炸与硬编码的陷阱（为什么旧思路会碰壁？）

### 3.1 通俗隐喻：全套全身基因测序的灾难与带 41 张身份证的笨拙补丁
在早期的自动化排查中，程序遇到了灾难性的 **1144 亿条 CPU 指令爆炸（114.4G Instructions）**，CI 基准测试直接被掐断：

- **早期致命误区（抓嫌犯先做全套全身 DNA 测序）**：  
  为了看一个人是不是合数、因数是不是质数，代码在每一步都去调用机器内核的默认素数检测（`decide p.Prime`）。在机器内核眼里，这相当于要对每个人从细胞核染色体第一对一直数到最后一对（皮亚诺归纳递归展开）。测一个 181 就能让机器爆栈，测 560 个人直接打出 1144 亿条计算指令！
- **次级方案的妥协（手工带 41 张身份证静态表）**：  
  为了避免爆栈，我们曾经人工整理了 41 个素数的静态表：
  - 测试表：`[3, 5, 7, ..., 37]`（11 个）
  - 商数表：`[41, 43, ..., 181]`（30 个）
  并在编译期手工逐个给这 41 个数字盖章发身份证（`norm_num` 证书）。
- **为什么“静态表”在开源顶刊（Mathlib）走不通？**  
  正如 Mathlib 资深维护者所指出的：**“代码一旦合入即成永久公共技术债（Code is permanent tech debt）”**。只要审稿人看到代码里塞了 30 多个毫无通式美感的硬编码常数，就会立刻打回：*“这属于临时打补丁，为什么不用纯粹优雅的数论工具解决？”*

### 3.3 严谨学术：内核规约机理与开源社区合入铁律
1. **114.4G 指令爆炸的内核机理**：  
   `Mathlib.Data.Nat.Prime.Defs` 中的 `Nat.decidablePrime` 是基于 `prime_def_lt'` 的有界全称量词递归展开。在 Lean 4 逻辑内核归约器（Kernel Reducer）中，计算一个数是否为素数会被展开为 $O(n^2)$ 个皮亚诺递归项。对于 $n = 181$，直接触发 `maximum recursion depth has been reached`。全域调用引发 1144 亿条指令。
2. **社区合入准则（Strict PR Checklist）**：  
   在 Lean 4 / Mathlib 单体库中，所有辅助定义和定理一旦合入 master，就会被上游全局依赖。硬编码的常数表（Magic Constants）缺乏数学泛化能力，不仅占用维护成本，更是形式化数学追求纯粹性时无法容忍的代码异味（Code Smell）。

### 4.1 通俗隐喻：只照一束紫外线与唯一漏网嫌疑犯 341
怎样才能**既不需要做全身基因测序，又彻底扔掉那张写着 41 个质数的笨拙身份证表**？

数学家告诉我们：**跳出科瑟尔特的因数分解思维，直接回归卡迈克尔数的原生定义！**
卡迈克尔数的定义是：必须骗过**所有**互素的验钞机（底数）。
这意味着：**要证明一个人不是卡迈克尔数，我们根本不需要知道他是由哪些素数零件组成的，我们只需要随便找一台验钞机，只要照出他的反射代码不是 1，就能瞬间一票否决！**

更奇妙的是数论世界的精妙对称：
- **偶数**：全部是良民，一行定理（卡迈克尔数必为奇数）瞬间排除；
- **素数**：素数是真钞，天然不是伪钞大师（卡迈克尔数必须是合数）；
- **全宇宙小于 561 的奇合数**：我们拿 **2 号波长（底数 2）** 照过去，**除了 341 这一张假钞以外，其余所有奇合数在底数 2 面前当场暴毙（全部反射代码不为 1）！**
- **唯一的漏网嫌疑犯 341（341 = 11 × 31）**：我们拿出 **3 号波长（底数 3）** 照一下，它的反射代码是 56，不是 1，当场落网！

**这就是终极的数学减法！**
- 0 张硬编码素数表！
- 0 次素因数分解！
- 0 次平方因子检查！
只需要做模快速幂，代码瞬间降维到极致纯净！

### 4.2 中文伪代码：费马证伪判定器算法

```text
算法 费马证伪快速安检门(待测自然数 n):
    输入: 自然数 n < 561
    输出: 布尔值 (真表示可能是卡迈克尔数，假表示确凿不是)

    // 步骤 1：排除小于等于 2 的数以及所有偶数
    如果 n ≤ 2 或者 n % 2 == 0:
        返回 假  // 卡迈克尔数必须是大于 2 的奇数

    // 原理：若 n < 561 是合数，必有因数 d ≤ √560 < 24
    // 若 2 到 23 中没有任何数能整除 n (且 d * d ≤ n)，则 n 必为素数！

    如果 n == 341:

    // 步骤 4：通杀其余所有奇合数（底数 2 照妖镜）
    否则:
        返回 检验底数同余(n, 底数 2)    // 其余奇合数全部余数不为 1，全部返回假
```

### 4.3 严谨学术：三素因子界、底数 2 唯一伪素数与同余证伪
1. **三素因子立方紧界定理**：  
   由 `IsCarmichael.three_le_card_primeFactors`，任何卡迈克尔数至少有 3 个不同素因子；由 `IsCarmichael.odd` 知其为奇数。
   若最小素因子 $p_{\min} \ge 11$，则 $n \ge 11 \times 13 \times 17 = 2431 > 561$，产生直接矛盾。因此小于 561 的卡迈克尔数其最小素因子必为 3、5 或 7。
2. **底数 2 的最小伪素数是 341**：  
   数论经典定理证实：以 2 为底的最小费马伪素数（Poulet 数）是 $341 = 11 \times 31$。在区间 $[3, 560]$ 内，不存在任何其他满足 $2^{n-1} \equiv 1 \pmod n$ 的奇合数。
3. **底数 3 对 341 的证伪**：  
   $3^{340} = 3^{10 \times 34} \equiv 1^{34} \equiv 1 \pmod{11}$，但 $3^3 = 27 \equiv -4 \pmod{31}$，经计算 $3^{340} \equiv 56 \not\equiv 1 \pmod{341}$。由于 $\gcd(3, 341) = 1$，341 违反了卡迈克尔数对全体互素底数均成立的要求，确凿被证伪。

```lean
    isCarmichaelCandidate n = true := by
  unfold isCarmichaelCandidate
  split_ifs with h2 hall h341
  · simp only [Bool.or_eq_true, decide_eq_true_iff] at h2
    rcases h2 with hle | heven
    · have := hc.two_lt; lia
    · obtain ⟨k, rfl⟩ := hc.odd; lia
  · have h_sqle := minFac_sq_le_self (by lia) hc.not_prime
    have h_mf_lt : minFac n < 24 := by
      by_contra! h24

      lia
    have hp : 2 ≤ minFac n := (minFac_prime (by lia)).two_le
    have hd_mem : minFac n ∈ List.range' 2 22 := by
      rw [List.mem_range']

    have hall_dvd := List.all_eq_true.mp hall (minFac n) hd_mem
```

```lean
    ∀ n < N, ¬ n.IsCarmichael := by

  have hall := List.all_eq_true.mp h n (List.mem_range.mpr hn)

  exact not_isCarmichael_of_lt_561 h hn
```
