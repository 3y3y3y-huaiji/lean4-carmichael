## 2. 需要修正的三处表述

1. **"2 状态自动机"** → 改为"两趟 2 状态转导"（parity fold + divide-by-2）。若坚持"自动机"，
   需说明它不是 Cobham 意义下的自动序列——事实上 `p(L) = 2^L`（§4）与 Stephan 的非 P-递归性
   都排除了有限自动机。
2. **"趋向 (1/3,1/3,1/3)"** → 改为"第 j 位在 j ≥ 3 后趋于均匀；低 3 位有精确刚性分布"。
   这一点反而是正面结果，见 §3。
3. **"末位二分状态机"** → 改为"末位是相邻奇偶对的**双向编码**"：
   `a_{n+1} mod 6 = 3·ε_{n+1} + 2·ε_n`（4 个值 ↔ 4 个 `(ε_n, ε_{n+1})`，Lean: `a_mod_six`）。
   这解释了为什么它看起来像状态机：它只是奇偶序列的移位寄存器，没有闭合的 4 状态转移。

## 3. 真正的结构：2-adic / 3-adic 对偶（建议作为论文主定理）

在 `Z₆ = Z₂ × Z₃` 的坐标下，`T(x) = (3x + (x mod 2))/2`：

- **3-adic 方向：`T` 是单射**，`|T(x)-T(y)|₃ = 3|x-y|₃`，像 = `{x : x ≢ 1 mod 3}`（测度 2/3）。
  逆枝 `y ↦ (2y - (2y mod 3))/3` 是**局部规则**，收缩 1/3。
- **2-adic 方向：每步消耗一位二进制**（`a_{n+1} mod 2^j` 由 `a_n mod 2^{j+1}` 决定）。

由此得到一对互补定理（k ≤ 6 均精确验证为双射）：

| 观察窗口 | 对应的东西 | 方向 |
| :-- | :-- | :-- |
| 末 k 位**三进制** `a_n mod 3^k` | 前 k 步奇偶 `(ε_{n-k},…,ε_{n-1})`，恰好 2^k 个类 | **向后**（3-adic 记忆） |
| 末 k 位**六进制** `a_n mod 6^k` | 后 k 步奇偶 `(ε_n,…,ε_{n+k-1})` | **向前**（2-adic 预测），第 k+1 步断崖 |

一句话：**低位三进制存的是"过去"，低位六进制（每位自带一位二进制）预测的是"未来"。**
`视角一` 与 `视角二` 不是两个独立现象，是同一个 `Z₂ × Z₃` 分解的两侧。

关键引理（已 Lean 化）：`ε_{n+1} = bit₁(a_n)`，即 `a_{n+1} % 2 = (a_n / 2) % 2`。
它把"六进制两位局部律"降维成一句位移陈述，也是断崖的成因：算下一步奇偶需要 `a_n mod 4`，
而 `mod 6` 不含 `mod 4` 的信息。

## 5. 解析式 `a_n = ⌊K(3/2)^n⌋` 的两行证明

由 `a_{n+1} = (3a_n + ε_n)/2`，`ε_n ∈{0,1}`：

```
K - a_n/(3/2)^n = Σ_{k≥n} ε_k (2/3)^{k+1} / 2  ≤  (2/3)^n ,
```

且等号不成立（否则 `ε_k ≡ 1` 恒成立，推出 `K·(3/2)^n ∈ Z` 对所有大 n 成立，矛盾）。
故 `(2/3)^n > K - a_n/(3/2)^n`，即 `a_n > K(3/2)^n - 1`，配合 `a_n ≤ K(3/2)^n` 得
`a_n = ⌊K(3/2)^n⌋`。`K = 1.08151366858984…`（Fraction 精确验证 n ≤ 399）。

注意：这与 Mahler 的 Z-number 定理**无关**（OEIS 明言 `K(3)` 不是 Z-number，因
`frac(K(3)(3/2)²) = 0.6501…`）。别在论文里写"由 Mahler 定理得"。

## 8. 关于"跨过信息悬崖"的建议

**没有墙可穿。** 原因是结构性的：奇偶序列只是 `Z₂` 坐标的读出，而 3-adic 位数（"高位结构"）
存的是**过去**的奇偶，不是未来。任何用一维自旋链/张量网络去"穿透高位边界"的做法，方向上
就错了——它预测不了下一步。

三个可做且可发表的方向：

1. **块熵实验代替自旋链**：测 `h(L) = log p(L)/L` 的增长率。若线性 ⇒ 正熵 ⇒ 非 sofic
   （已由 `p(L)=2^L` 强烈支持）。张量网络在这里只会复现 `p(L)=2^L`，不提供新信息。
2. **把对偶性写成定理**（§3）：`a_n mod 3^k ↔ (ε_{n-k},…,ε_{n-1})` 双射。可逆性方向已经在
   Lean 里（`step_pow_bstep` / `bstep_pow_step`），只差基数那一步；它同时能解释低位三进制分布
   (1/2,0,1/2)、(1/4,1/2,1/4) 的刚性。
3. **等分布问题**：40 年未决的 Mahler 型问题在这里的化身是"2-adic 轨道 `1, 2, 3, 5, 8, …`
   是否等分布"。这比"物理方法"更接近真问题；建议把它明确写成一个猜想，而不是用动力学模拟去
   "检验"。
