# Lean 4 严格强制求值性能实测基准 (Benchmark)

本目录包含用于实测 Lean 4 计算反射（Computational Reflection）决策算法与经形式化验证的埃拉托斯特尼筛法（Sieve of Eratosthenes）**严格纯计算执行时间**的基准测试脚本。

## 基准设计与测试真实性保障

为了彻底杜绝惰性求值与编译器死代码消除偏差：
1. **严格强制求值**：将数组生成（`Array.ofFn`）与 100% 内存遍历读取全部关进 `IO.monoNanosNow` 单调纳秒计时器内部。
2. **纳秒级精度**：精准统计微秒（$\mu\text{s}$）与毫秒（$\text{ms}$）级别纯算法耗时。

---

## 实测性能表现

测试环境：`leanprover/lean4:v4.33.1`，单核计算：

| 评测目标 | 规模 / 范围 | 实测纯计算耗时 | 说明 |
|---|---|---|---|
| **561 极小性判定** (`checkCarmichaelBound 561`) | $N = 561$ | **226 微秒**（约 0.22 毫秒） | 瞬时完成 560 个候选数排查与证书生成 |
| **埃拉托斯特尼筛法全量遍历** | $N = 1,000$ | **1.11 毫秒** | 检出 171 个素数 |
| **埃拉托斯特尼筛法全量遍历** | $N = 5,000$ | **1.58 毫秒** | 检出 819 个素数 |
| **埃拉托斯特尼筛法全量遍历** | $N = 10,000$ | **2.90 毫秒** | 检出 1,642 个素数 |
| **埃拉托斯特尼筛法全量遍历** | $N = 50,000$ | **15.90 毫秒** | 检出 8,194 个素数 |
| **埃拉托斯特尼筛法全量遍历** | $N = 100,000$ | **29.07 毫秒** | 检出 16,369 个素数 |

## 运行复现方法

- **中文控制台**：
  ```powershell
  pwsh ./benchmark/run_benchmark_zh.ps1
  ```

